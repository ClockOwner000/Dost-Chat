Neeche wala button dabao, app aap ke phone ki home screen par aa jayegi.

✔ Install ho gayi. Ab home screen se kholo.
Ye link kisi app ke andar khula ha. Install ke liye Chrome chahiye.
  1. Upar ya neeche 3 dots dabao.
  2. "Open in Chrome" ya "Browser mein kholo" chuno.
Chrome mein kholo
iPhone par:
  1. Ye page Safari mein kholo (Chrome mein nahi hota).
  2. Neeche Share button dabao.
  3. "Add to Home Screen" chuno, phir Add.
Button na aaye to:
  1. Chrome ke upar wale 3 dots dabao.
  2. "Install app" ya "Add to Home screen" chuno.
  3. Agar wahan ye dono na hon to "Desktop site" ka tick hata do aur Incognito se bahar aao.
Pehle se install ho to ye option nahi aata. Home screen par Clock dhoondo.
